# DataCon 2026 — проектное портфолио

**Участник:** Никита Евстигнеев, GitHub [NikkiRe](https://github.com/NikkiRe).

**Результат:** третье место на хакатоне «DataCon 2026: мультиагентная экстракция
данных». Именной диплом получен; он хранится в личном пакете документов и не
публикуется в репозитории.

## Задача и решение

Командное решение ChemX Extract преобразует научные PDF в структурированные CSV
по схемам бенчмарка [ChemX](https://github.com/ai-chem/ChemX). В текущем `main`
предусмотрены обработка текста, таблиц и изображений, LLM-извлечение, второй проход
проверки записей, нормализация и обработка химических структур SMILES. Доступны
девять схем доменов, CLI и веб-интерфейс Streamlit.

## Мой основной вклад

- **Прототип Nanozymes в отдельной ветке `task1`.** Извлечение из PDF/текста в
  записи по JSON Schema, нормализация и сериализация, расчёт precision/recall/F1,
  инструменты загрузки данных и запуска. Исходная реализация —
  [`cc5ab3d`](https://github.com/NikkiRe/DataCon2026/commit/cc5ab3d).
- **Интерфейс итогового решения.** Выбор режимов `fast` / `pdf` / `staged` и
  верификации, фоновая обработка с отображением статуса и ошибок, кэширование по
  PDF и параметрам, таблица результата, сводка заполненности полей и экспорт CSV.
  Коммит [`4bd3500`](https://github.com/NikkiRe/DataCon2026/commit/4bd3500) вошёл в
  `main`.
- **Инструкции запуска и проверки.** Переработка README, `RUN.md` и описания
  задачи. Коммит [`477fd68`](https://github.com/NikkiRe/DataCon2026/commit/477fd68)
  вошёл в `main`.

Ветка `task1` представляет самостоятельный вариант прототипа и не является
предком текущего `main`. В `main` используется командная линия `chemx_extract`.

## Командная работа

Проект выполнен совместно. В исходной истории сохранены изменения NikkiRe,
Kirill Sleptsov и yura. Реализация текущего пайплайна в `main` включает вклад
нескольких участников; здесь перечислен мой конкретный вклад. Этот форк
сохраняет связь с [исходным командным репозиторием](https://github.com/Sleptsov99/DataCon2026).

## Проверяемые результаты и ограничения

Третье место подтверждено именным дипломом. Итоговый измеренный Macro-F1
командного решения в текущем публичном репозитории не опубликован. Файлы
`metrics/metrics_*_from_single_agent.csv` относятся к бейзлайнам организаторов;
они не являются метриками нашей команды. Поддержка девяти схем не означает
доказанного превосходства во всех девяти доменах.

Запуск LLM требует ключей провайдера и может быть платным. При подготовке этой
портфолио-версии API-вызовы и повторное измерение качества не выполнялись.
