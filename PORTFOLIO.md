**Участник:** Никита Евстигнеев, GitHub [NikkiRe](https://github.com/NikkiRe).

**Результат:** 3-е место на хакатоне «DataCon 2026: мультиагентная экстракция
данных» (командный результат).

## Задача и решение

Командное решение ChemX Extract преобразует научные PDF в структурированные CSV
по схемам бенчмарка [ChemX](https://github.com/ai-chem/ChemX). В текущем `main`
предусмотрены обработка текста, таблиц и изображений, LLM-извлечение, второй проход
проверки записей, нормализация и обработка химических структур SMILES. Доступны
девять схем доменов, CLI и веб-интерфейс Streamlit.

## Мой основной вклад

- **Прототип Nanozymes в отдельной ветке `task1`.** Извлечение из PDF/текста в
  записи по JSON Schema, нормализация и сериализация, реализация метрики ChemX
  (precision/recall/F1 по полям, Macro-F1), скрипты загрузки данных и запуска.
  Исходная реализация —
  [`cc5ab3d`](https://github.com/NikkiRe/DataCon2026/commit/cc5ab3d).
- **Доработка Streamlit-интерфейса итогового решения**
  ([`4bd3500`](https://github.com/NikkiRe/DataCon2026/commit/4bd3500), вошёл в
  `main`). До коммита приложение позволяло выбрать домен, загрузить PDF, получить
  таблицу и выгрузить CSV. Коммит добавил выбор режима (`fast` / `pdf` / `staged`)
  и переключатель второго прохода верификации, извлечение в фоновом потоке со
  статусом и временем выполнения, отдельное сообщение при rate limit (429), кэш
  результата по SHA-256 PDF и параметрам, сводку заполненности полей и блок
  предрасчитанных примеров из `app/examples/` (CSV-примеров в репозитории нет,
  поэтому блок не отображается).
- **Инструкции запуска и проверки.** Переработка README, `RUN.md` и описания
  задачи. Коммит [`477fd68`](https://github.com/NikkiRe/DataCon2026/commit/477fd68)
  вошёл в `main`.

Ветка `task1` — самостоятельный вариант прототипа, она не является предком
текущего `main`. В `main` используется командная линия `chemx_extract`.

## Командная работа

Проект выполнен совместно. В исходной истории сохранены изменения NikkiRe,
Kirill Sleptsov и yura. Реализация текущего пайплайна в `main` включает вклад
нескольких участников; здесь перечислен мой конкретный вклад. Этот форк
сохраняет связь с [исходным командным репозиторием](https://github.com/Sleptsov99/DataCon2026).

## Метрики

Итоговый Macro-F1 командного решения в репозитории не опубликован. Файлы
`metrics/metrics_*_from_single_agent.csv` — метрики бейзлайна ChemX
(single-agent), а не нашей команды. Метрику на своих предсказаниях считает
`scripts/run_eval.py` (см. [RUN.md](RUN.md)). Для извлечения нужен ключ Anthropic
и/или OpenAI; вызовы платные.
